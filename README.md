# DRAFT XI

터치라인(3D/2D 경기 엔진 · FM식 전술)과 Road to Legend(화면 구성 · 로고/국기 팩 · 기록 화면)를 합친 드래프트 축구 감독 게임입니다.
빌드 과정이 없는 정적 사이트라, 이 폴더를 그대로 GitHub에 올리고 Vercel에서 프레임워크 "Other"로 배포하면 됩니다.

## 흐름
1. **새 대회** — 형식(리그 / 토너먼트 / 조별리그+토너먼트 / 리그 페이즈+토너먼트), 감독 수, 선수 풀(실존 FC27 · 가상 · 혼합, 능력치·나이·리그 범위), 드래프트 방식, 스쿼드 크기, 재드래프트 횟수, 팀(실제 구단 / 가상 구단, 상대 팀 자동·직접 지정)
2. **드래프트** — 셔플(20명 세트에서 1명 뽑고 옆으로 넘기기) / 스네이크 / 포지션 5지선다
3. **대회** — 전술·선발·세트피스(터치라인 전술 화면 그대로), 경기 보기 또는 결과만 보기, 라운드 사이 재드래프트
4. **기록** — 경기별 요약·통계·라인업 평점·슈팅 맵·선수 기록, 대회 개인/팀 순위, 라운드·대회 베스트 11, 지난 경기 다시 보기

## 경기 계산
- 모든 경기(내 경기, AI끼리의 경기)는 같은 터치라인 엔진으로 90분을 계산합니다. 다른 경기는 워커에서 동시에 돌아갑니다.
- 토너먼트에서 90분 동안 비기면 연장전(기대 득점 기반 통계 모델)과 승부차기(키커 페널티 능력치 vs 골키퍼)로 승자를 가립니다.
- 경기 사이에는 체력이 모두 회복됩니다. 출전 정지(퇴장 1경기, 경고 3장 누적 1경기)는 설정에서 끌 수 있습니다.

## 멀티플레이를 붙일 때
지금은 AI 감독만 있지만, 구조는 여러 사람이 참가하는 경우를 전제로 짰습니다.
- 감독마다 `ctrl`(`'user'` / `'ai'`)과 `uid`가 있습니다. `ctrl`이 `'ai'`가 아닌 감독이 여럿이어도 드래프트 로직은 그대로 동작합니다(모두 고를 때까지 라운드가 넘어가지 않음).
- 상태를 바꾸는 길은 `DXC.draftPick`, `DXC.draftAdvance`, `DXC.redraft`, `DXC.applyResult`, `DXC.advance` 다섯 가지뿐이고, 난수는 전부 대회 시드(`T.seed`)에서 나옵니다. 같은 호출을 같은 순서로 재생하면 어느 기기에서든 같은 상태가 됩니다.
- 붙일 것: 방(대회 객체 공유) + 위 호출을 순서대로 전달하는 서버. 화면 쪽은 `dx_ui.js`의 `ME`(지금은 0번 감독 고정)를 접속한 사람의 감독 번호로 바꾸면 됩니다.
- 경기 결과는 한 곳(방장 또는 서버)에서 계산해 `applyResult`로 나눠 주는 방식을 권합니다.

## 전술 화면
- 경기장의 선수를 누르면 팝업에서 역할(플레이 스타일)·개인 지침·그 자리에 넣을 선수를 한 번에 고릅니다.
- `선발 배치 / 공 소유 시 / 공 미소유 시` 전환: 낮은·중간·높은 라인별 예상 위치, 움직임 범위(타원), 커버 영역(칸마다 담당 선수 이름, 빈 공간 표시)을 켜고 끌 수 있습니다. 엔진 움직임을 단순화한 예상도입니다(`app.js`의 `shapeModel`).
- 팀 지침: 전술 스타일 10종(`dx_core.js`의 `STYLES`)과 성향 7단계(`MENTS`)를 고른 뒤 각 지침을 바꿔 변주합니다. 성향은 수비 라인·압박 기준선·템포·압박 강도·시간 지연을 함께 움직입니다.

## 경기 화면
- 기록 영역 4개(오른쪽 2개 + 하이라이트 사이 화면 2개)마다 드롭다운이나 ◀ ▶로 볼 기록을 고릅니다: 해설, 경기 통계, 팀별 평점·체력, 슈팅 맵, xG 흐름, 팀별 패스 맵, 전술 진단, 선택한 선수.
- 하이라이트 보기 방식에서는 주요 장면에만 경기장이 나오고, 그 사이에는 기록 화면이 넓게 나옵니다. `화면 설정`에서 경기장을 계속 보이게 할 수 있습니다.

## 역할과 배치 (소유 시 / 미소유 시)
- 자리마다 **공 소유 시 역할**(`engine.js`의 `ROLES`)과 **공 미소유 시 역할**(`DROLES`)을 따로 고릅니다. 역할 카드에는 설명, 주요 능력치(선수의 실제 값), 어울리는 성향이 나옵니다.
- 배치도 따로 정합니다. `공 미소유 시 배치`에서 포메이션을 고르거나 바둑알을 끌어 옮기면 `setup.slotsOop`에 저장되고, 엔진은 공을 잃었을 때 그 자리를 기준으로 블록을 만듭니다(없으면 소유 시 배치와 같음).
- 능력치 적용(자리 익숙함)은 소유 시 포지션 기준입니다. 미소유 시 포지션의 익숙함은 따로 계산하지 않습니다.
- AI 감독은 스타일에 따라 미소유 시 역할(압박형·버티기형·역습 대기형)과 미소유 시 포메이션(예: 유동적 역습 4-2-3-1 → 4-4-2)을 씁니다.

## 경기 중 기능
- **전술 조정(퀵 조정)**: 전술 화면을 열지 않고 팀·선수 단위 조정을 켜고 끕니다(`app.js`의 `TW_TEAM`, `TW_PL`). 여러 개를 동시에 켤 수 있고 끌 때까지 유지됩니다. 기본 전술은 `setup.tw.base`에 보관하고, 켜진 조정을 그 위에 얹어 계산합니다.
- **세부 스탯**: 양 팀 모든 선수의 기록 표(정렬 가능), 선수별 히트맵·패스·평가.
- **AI 감독의 실시간 대응**: `engine.js`의 `aiAdapt`가 약 9분마다 지난 구간의 실점 위험 유형(뒷공간·크로스·역습·중거리), 공격 부진, 점수 상황을 보고 지침과 미소유 시 역할을 고칩니다.
- 단축키: 스페이스 재생/일시정지 · T 전술·교체 · Q 전술 조정 · S 세부 스탯 · R 리플레이

## 경기 엔진의 움직임 (물리)
- 선수: 가속은 속도가 붙을수록 약해지고 제동은 더 강합니다. 몸 방향은 회전 속도 한계 안에서만 돌아가며, 빨리 달릴수록 급히 틀 수 없습니다(`engine.js`의 `maxAcc`, `turnRate`, `movePlayers`).
- 공을 받으면 퍼스트 터치 시간(공 속도·높이·볼 컨트롤에 따라)이 지난 뒤에 다음 동작을 고릅니다(`gain`). 패스하려는 방향이 몸 방향과 많이 다르면 먼저 몸을 돌립니다(`decide`의 조준 동작).
- 공이 지나가는 길목 가까이 있는 선수는 그 자리로 움직여 발을 뻗고, 받는 선수가 못 닿는 패스는 가까운 동료가 대신 받으러 갑니다(`assignChasers`).
- 3D 보기에서는 빨리 감는 동안 2D로 바뀌고, 정배속 장면과 리플레이에서만 3D가 됩니다(설정에서 끌 수 있음).

## 7차 변경 (엔진 물리 · 경기 분석 · 밸런스)

### 엔진
- 공 마찰: 잔디 위 감속을 `a = 1.75 + 0.011·v²`(m/s²)로 바꿔 굴러가는 공이 금방 죽습니다. 패스 세기는 받는 지점 도착 속도에서 역산합니다.
- 휘는 공: 크로스는 골문 쪽으로 감기고, 긴 땅볼·로빙 패스도 커브 능력치에 따라 휩니다. 2D에서는 빠른 공에 잔상이 붙습니다.
- 몸 충돌: 슈팅 경로 한가운데(반경 0.42m, 높이 1.8m) 서 있는 선수는 거의 항상 막습니다. 패스가 상대 몸 중앙으로 오면 끊지 못해도 맞고 튑니다. 선수끼리는 겹치지 않고 힘·균형에 따라 밀립니다.
- 골키퍼: 박스 안으로 들어올 공은 4초 앞까지 예측해 미리 나갑니다.
- 준비 동작: 패스 0.15~0.26초, 슈팅 0.24~0.34초 동안 디딤발을 딛고 다리를 뒤로 뺍니다(애니메이션 14). 이 사이에 태클당할 수 있습니다.
- 드리블: 달릴 때 공을 앞으로 쳐 놓고 따라가며, 수비수 앞에서는 스텝오버(애니메이션 15)가 나옵니다. 빈 공간에서는 거의 전력으로 달립니다.
- 기본 수비: 자기 골문 40m 안에서는 압박 설정과 무관하게 2~3명이 볼 보유자를 막아섭니다. 최전방 공격수는 블록이 내려가도 하프라인 근처에 남습니다.

### 전술 밸런스
- 원인: 압박·높은 라인 스타일이 내려앉는 스타일을 같은 전력에서 일방적으로 이겼습니다(게겐프레스 평균 4.6득점 0.6실점, 버스 세우기 1.1득점 3.4실점).
- 조치: 수비 라인·개입 라인의 효과 폭 축소, 재압박 인원 3→2명, 압박 중 체력 소모 1.3배, 뒷공간 스루패스 강화, 약한 스타일의 불리한 기본 지침 정리.
- 결과(AI 대 AI, 전력 비슷): 4골 차 이상 경기 27% → 3%(60경기). 버스 세우기는 여전히 가장 약합니다.

### 화면
- 전술 탭: 원형 = 포지션·역할 편집, 이름 = 선수 능력치 창.
- 경기 분석 탭(`dx_review.js`): 개요(팀 평가, 기록 비교, 누적 xG, 5분 단위 흐름), 팀 지표 4분면 8종, 히트맵·평균 위치·패스 연결망, 패스맵, 슈팅, 선수별 평가(팔각형 + 잘한 점/부족한 점). 히트맵·패스 기록은 내 팀의 가장 최근 경기 1개만 저장합니다(`T.last`).
- 순위표 엠블럼 확대, AI 무작위 구단은 로고가 있는 구단만.
- 3D: 선수 크기 설정(기본 1.15배), 준비 동작·스텝오버 포즈 추가. 이 변경은 3D 화면에서 실행해 확인하지 못했습니다.

## 8차 변경 (화면 이동 · 팀 정보 · 경기 중 조정)
- 팀 이름은 어디서든 누르면 팀 정보 화면(개요·포메이션·전술·지표 / 선수단 / 경기 결과)으로 이동합니다. 상단 메뉴 '스쿼드'는 '팀 정보'로 바뀌었습니다.
- 모든 대회 화면 위에 뒤로/앞으로 버튼과 이동 경로가 표시되고, 브라우저의 뒤로 가기와도 연동됩니다.
- 전술 진단 카드에 '실행할 조정'과 실행 버튼이 붙었습니다(빠른 전술 조정을 켜는 방식).
- 빠른 전술 조정: 기본 전술에 이미 들어 있는 상태는 초록 테두리 + '기본' 표시, 최대치면 눌리지 않습니다.
- 경기 화면: 이름 아래 포지션 표시 옵션(재생·화면 설정, 설정 화면).
- 경기 중 평점·세부 스탯·부문별 1위·득점자·선수단 대화·교체 목록의 이름도 선수 창으로 연결됩니다.
- 선수 기록 목록, 베스트 11, 수상, 경기 최우수 선수에 소속 팀 엠블럼을 표시합니다.

## 9차 변경 (3D 선수 몸체 · 공)
- 3D 선수: 내장 마네킹(X Bot)은 뼈대와 달리기 애니메이션만 쓰고, 겉모습은 뼈마다 직접 만든 부위(머리·머리카락·목·몸통·반소매·팔·손·하의·허벅지·양말·축구화)를 붙입니다. 어깨 폭 43cm, 허리 32cm, 키 179cm 기준. 골키퍼는 긴소매와 장갑. `render3d.js`의 `buildBody`.
- 설정의 3D 선수 모델: 사람 모델(새 몸체) / 마네킹(이전) / 단순 모델.
- 공: 흰 바탕에 굽은 띠 무늬 12개(3D), 2D에도 굴러가며 도는 무늬.
- 3D 변경은 실행 환경이 없어 화면으로 확인하지 못했습니다. 몸체 치수는 뼈 좌표로 정면·측면 도면을 그려 확인했습니다.
