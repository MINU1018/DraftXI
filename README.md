# DRAFT XI

터치라인(3D/2D 경기 엔진 · FM식 전술)과 Road to Legend(화면 구성 · 로고/국기 팩 · 기록 화면)를 합친 드래프트 축구 감독 게임입니다.
빌드 과정이 없는 정적 사이트라, 이 폴더를 그대로 GitHub에 올리고 Vercel에서 프레임워크 "Other"로 배포하면 됩니다.

## 흐름
1. **새 대회** — 형식(리그 / 토너먼트 / 조별리그+토너먼트 / 리그 페이즈+토너먼트), 감독 수, 선수 풀(실존 FC27 · 가상 · 혼합, 능력치·나이·리그 범위), 드래프트 방식, 스쿼드 크기, 재드래프트 횟수, 팀(실제 구단 / 가상 구단, 상대 팀 자동·직접 지정)
2. **드래프트** — 셔플(20명 세트에서 1명 뽑고 옆으로 넘기기) / 스네이크 / 포지션 5지선다
3. **대회** — 전술·선발·세트피스(터치라인 전술 화면 그대로), 경기 보기 또는 결과만 보기, 라운드 사이 재드래프트
4. **기록** — 경기별 요약·통계·라인업 평점·슈팅 맵·선수 기록, 대회 개인/팀 순위, 라운드·대회 베스트 11, 지난 경기 다시 보기

## 파일
| 파일 | 내용 |
|---|---|
| `dx_core.js` | 화면 없는 게임 로직: 선수 풀, 드래프트, AI 감독, 대회 진행, 연장·승부차기, 기록 집계 |
| `dx_ui.js` | 저장, 홈, 새 대회 설정, 드래프트 룸 |
| `dx_ui2.js` | 대회 허브, 경기 진행, 스쿼드·전술·일정·순위·기록·드래프트 보드, 경기 상세, 선수 프로필 |
| `dx_worker.js` | 다른 감독들의 경기를 뒤에서 계산하는 워커 |
| `app.js`, `engine.js`, `data*.js`, `render2d.js`, `render3d.js`, `lib/` | 터치라인에서 가져온 경기 엔진·전술 화면·경기 화면 (app.js는 드래프트 게임용으로 메뉴와 저장 키만 수정) |
| `logos_pack.js`, `flags_pack.js` | Road to Legend의 구단 로고·국기 팩 |

## 경기 계산
- 모든 경기(내 경기, AI끼리의 경기)는 같은 터치라인 엔진으로 90분을 계산합니다. 다른 경기는 워커에서 동시에 돌아갑니다.
- 토너먼트에서 90분 동안 비기면 연장전(기대 득점 기반 통계 모델)과 승부차기(키커 페널티 능력치 vs 골키퍼)로 승자를 가립니다.
- 경기 사이에는 체력이 모두 회복됩니다. 출전 정지(퇴장 1경기, 경고 3장 누적 1경기)는 설정에서 끌 수 있습니다.

## 멀티플레이를 붙일 때
지금은 AI 감독만 있지만, 구조는 여러 사람이 참가하는 경우를 전제로 짰습니다.
- 감독마다 `ctrl`(`'user'` / `'ai'`)과 `uid`가 있습니다. `ctrl`이 `'ai'`가 아닌 감독이 여럿이어도 드래프트 로직은 그대로 동작합니다(모두 고를 때까지 라운드가 넘어가지 않음).
- 상태를 바꾸는 길은 `DXC.draftPick`, `DXC.draftAdvance`, `DXC.redraft`, `DXC.applyResult`, `DXC.advance` 다섯 가지뿐이고, 난수는 전부 대회 시드(`T.seed`)에서 나옵니다. 같은 호출을 같은 순서로 재생하면 어느 기기에서든 같은 상태가 됩니다.
- 붙일 것: 방(대회 객체 공유) + 위 호출을 순서대로 전달하는 서버. 화면 쪽은 `dx_ui.js`의 `ME`(지금은 0번 감독 고정)를 접속한 사람의 감독 번호로 바꾸면 됩니다.
- 경기 결과는 한 곳(방장 또는 서버)에서 계산해 `applyResult`로 나눠 주는 방식을 권합니다.
